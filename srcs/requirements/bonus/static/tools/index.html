What is Inception?

Inception is a project from 42 focused on Docker, containers and system administration.

The goal is to create an infrastructure where each service runs inside its own Docker container.

Our Infrastructure

NGINX

Handles HTTPS connections.

WordPress

Runs the website using PHP-FPM.

MariaDB

Stores the WordPress database.

Redis

Provides caching for WordPress.

Adminer

Allows database administration.

FTP

Provides access to WordPress files.

Docker Architecture

All services communicate through a Docker network.

User → NGINX → WordPress → MariaDB

WordPress → Redis
