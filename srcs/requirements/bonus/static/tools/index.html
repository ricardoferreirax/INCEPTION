INCEPTION

42 Lisboa - System Administration Project

What is Inception?

Inception is a 42 project about Docker and system administration.

The goal is to create an infrastructure where each service runs inside its own Docker container.

Services

NGINX

Handles secure HTTPS connections.

WordPress

Runs the main website using PHP-FPM.

MariaDB

Stores the WordPress database.

Redis

Provides caching for WordPress.

Adminer

Provides access to the MariaDB database.

FTP

Provides access to the WordPress files.

Architecture

Client → NGINX → WordPress → MariaDB

WordPress → Redis
